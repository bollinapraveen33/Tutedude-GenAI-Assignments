# Assignment 1: Python - Data Structures

## Overview

This assignment demonstrates basic Python data structures and their operations using a simple e-commerce product example.

The assignment covers:
- Lists
- Tuples
- Sets
- Dictionaries
- Basic data structure operations

## Files Included

### task1.py - Product Collections
- Creates a list with 6 product names.
- Creates a tuple containing product name, price, and category.
- Prints the second and last products.
- Adds two new products to the list.
- Converts a tuple to a list, changes the price, and converts it back to a tuple.

### task2.py - Categories
- Creates a category list matching the products.
- Converts the category list into a set.
- Demonstrates that duplicate categories are ignored.
- Adds a new category.
- Checks whether categories exist in the set.
- Displays the number of unique categories.

### task3.py - Product Pricing
- Creates a dictionary with product names and prices.
- Adds a new product.
- Updates an existing product price.
- Removes products.
- Calculates the average product price.
- Finds the product with the maximum price.

### task4.py - Combined Operations
- Creates a list of product tuples containing product name, price, and category.
- Creates a dictionary that maps each category to its products.
- Finds the category containing the maximum number of products.
- Prints all products belonging to that category.

## Requirements

- Python 3
- No external libraries are required.
- The programs use basic Python data structures and operations only.

## How to Run

Open a terminal in this folder and run each file separately:

    python task1.py
    python task2.py
    python task3.py
    python task4.py

## Restrictions Followed

- No external libraries are used.
- No pandas or numpy are used.
- No advanced topics are introduced.
- The programs focus on lists, tuples, sets, dictionaries, and their basic operations.
- Each task is provided in a separate Python file.
