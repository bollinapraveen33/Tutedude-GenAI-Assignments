# TuteDude Assignment 10: Pandas

## Overview

This assignment focuses on using Pandas to work with Series and
DataFrames, perform mathematical operations, filter data, analyze
student marks, and explore sales revenue using simple plots.

## Objectives

Create and manipulate Pandas Series.
Perform mathematical and statistical operations on Series.
Use lambda functions and conditional checks.
Create and inspect DataFrames.
Apply important DataFrame functions.
Filter rows using conditions.
Group data and calculate summary statistics.
Create simple plots using Pandas built-in plotting.

## Assignment Tasks

### Task 1: Pandas Series Basics

-   Create a Series from student marks: `78, 85, 90, 66, 72`.
-   Display the Series values, index, and data type.
-   Access the first element and the last two elements.

### Task 2: Mathematical Operations on Series

Perform these operations on the marks: - Add 5 to every mark. - Subtract
2 from every mark. - Multiply every mark by 1.05. - Divide every mark
by 2.

### Task 3: Python Functionalities on Series

-   Find the maximum, minimum, sum, and mean of the marks.
-   Use a lambda function to check whether each student passed
    (marks >= 70).
-   Count the number of students who passed.

### Task 4: Create a DataFrame

Create a student DataFrame with the columns Name, Marks, and
Subject. - Display the first three rows and last two rows. - Display
the DataFrame shape and column names.

### Task 5: Important DataFrame Functions

Use the DataFrame to display: - info() - describe() - head() -
tail()

Sort students by marks in descending order and reset the index.

### Task 6: Filtering and Conditional Selection

Select: - Students who scored more than 75 marks. - Students studying
Mathematics. - Students whose marks are above the average. - Students
who failed (marks below 70).

### Task 7: Grouping and Basic Analysis

Group students by subject and calculate: - Average marks per subject. -
Number of students per subject. - Maximum marks per subject.

### Task 8: Pandas Plotting

Create simple plots using Pandas built-in plotting: - Bar graph of
student names versus marks. - Line graph of marks. - Histogram of marks.

### Task 9: Mini Use Case --- Sales Data Analysis

Create a sales DataFrame containing daily revenue. - Calculate total
revenue. - Calculate average daily revenue. - Find the day with the
highest revenue. - Find days when revenue is above average. - Plot
revenue by day using a bar graph, line graph, and histogram.
